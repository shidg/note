4. 关键知识点：

​	CUDA：

​	NVIDIA 的 GPU 编程平台。
 	业务意义：

- PyTorch / TensorFlow 必须依赖 CUDA
- 模型训练、推理都需要它
- CUDA 版本必须和驱动、框架完全匹配



​	 TensorRT：

​	NVIDIA 的 **推理加速框架**，作用：

- 将 FP32/PyTorch 模型转换成 FP16/INT8 engine
- 在实时视频推理中可把速度提升 **3–10 倍**
- 企业级 GPU 推理平台必备组件

​	做“视频 AI 推理”，TensorRT 是强依赖。



​	 Python：

​	承载 AI 框架：

- PyTorch / TensorFlow
- OpenCV
- 视频处理库（ffmpeg、Decord、PyAV）
- 业务推理代码



​	“Driver-based 镜像” 是什么意思？

​	这是 K8s + GPU 场景下常用术语：

**driver-based 镜像 = 不包含 GPU 驱动，由宿主机驱动完成 GPU 映射**

也就是：

- 宿主机安装：NVIDIA 驱动 + nvidia-container-toolkit
- 容器内部不需要安装 GPU 驱动（也不能装）
- 通过 `/dev/nvidia*` + runtime 映射 GPU 能力

生产集群必须这样做，否则镜像会变得巨大、难以维护。

6. “实际生产可用”的 Dockerfile 示例

（适用于视频推理服务，基于 TensorRT）

```
FROM nvcr.io/nvidia/tensorrt:24.02-py3

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    python3-dev python3-pip python3-opencv ffmpeg \
    && rm -rf /var/lib/apt/lists/*

# 安装 Python 包
RUN pip install --upgrade pip && \
    pip install \
        numpy \
        onnx \
        onnxruntime-gpu \
        torch \
        torchvision \
        opencv-python \
        decord \
        pyyaml \
        fastapi uvicorn

# 拷贝业务代码
COPY app/ /workspace/app

# 默认启动命令
CMD ["python3", "/workspace/app/main.py"]
```

特点：

- 不含驱动（driver-based）

- 适合 K8s GPU 集群

- 包含 TensorRT、PyTorch、ONNX 推理链路

- 包含视频处理所需库
